# Equation word execution witnesses

These synthetic inputs exercise incoming native word state at the shared
formula boundary. They retain structured mathematical owners where their
complete accepted contents survive execution.

`matrix.json` records the finite Cartesian product of man/mdoc, filled/no-fill,
five incoming states, six equation payloads, two source-line origins and three
suffix arrangements. The 720 exact sources are also regenerated by the Rust
test. Each recorded source is compared byte-for-byte with its generated form.
The SHA-256 identifies the original input for independent replay.

The six payloads distinguish ordinary atoms, two atoms, a truly empty root, an
explicit empty atom, one author space and two author spaces. In particular,
configuration-only roots and empty words have different execution effects.
The native `roff_eqndelim` source guards are part of these exact sources.

Each source ran the pinned pristine reference in ASCII, UTF-8, HTML, tree and
lint profiles before expectations were written. ASCII, UTF-8, HTML and tree
returned zero for all inputs. Some minimal mdoc inputs intentionally produce
lint warnings about missing conventional manual sections. Warning-bearing
inputs retain their parsed content owners.

The body projection removes only the fixed five-cell terminal page margin and
the first filled row's automatic initial blank. It retains every accepted author
space, empty physical row and line boundary. The reference's terminal font
writes are evaluated as cells.
The stored raw rows for collisions and damaged candidates retain backspaces
and font layers. Genuine glyph overwrites select the final accepted cells.
An incoming bare `\z` can also consume a two-atom formula's internal blank.
A pending `\p` can split its atoms across physical rows.
Those cases permit accepted text with a mathematical coverage finding.
Equation publication requires a canonical reading consistent with the accepted
glyphs and internal blanks.

`families.json` adds 118 owner, mode, mathematical shape, retirement and empty
input witnesses. Genuine mdoc `.It Xo` HEAD equations remain in HEAD. Equations
in a native `.TP` BODY remain in BODY. A literal tagged HEAD can flush its
NOBREAK field onto the same physical row, retaining exactly two field blanks. URI and mail links distinguish label
content from incoming text outside the link. Font, spacing, keep and paragraph
boundaries exercise the same execution entry. Empty configuration and roots
retain zero paragraph and mathematical display owners. Quoted `printf(3)` remains a literal mathematical operand.

Mathematical shape witnesses compare exact surrounding text and complete
formula identities separately from the formula's canonical reading. This
allows canonical `x _ i ^ j` to differ from the native terminal's `x_i^j`.
The formula expression must still validate and retain supported structure.
Both Markdown policies are read with the CommonMark parser. The ordinary
matrix decodes only its fixed x/y font and text wrappers, preserving literal
spaces. Shape witnesses assert real mathematical or code-span events and
exact text outside them.

Every permanent case crosses the actual `QueryBundle` JSON string boundary.
The matrix also checks plain text, both Markdown policies and visible literal
search with canonical Markdown coordinates. The eight exploratory quoted-atom
internal `\c`/`\p` cases remain outside this fixture because those controls
have a separately documented approximation contract.
