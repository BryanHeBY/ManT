# Source execution scope boundaries

This finite matrix keeps ordinary source execution distinct from IR owner
drains. Every complete input ran the pinned pristine mandoc reference in five
profiles before its behavioral assertion was written. `cases.json` retains
source bytes and SHA-256, axes, profile exit/stdout/stderr hashes, explicit
native evidence and selected consumer obligations. Raw full-page outputs and
old candidate binaries stay in ignored audit evidence, not this fixture.

| Cohort | Complete sources | Independent witness |
| --- | ---: | --- |
| Name-field lifecycle | 181 | The 96 original SY combinations plus origin, mode, word, sequence, identity and finite-width controls, three original Nm protections, and four man interactions. |
| Table owner handoff | 120 | Ten parent contexts × four predecessors × three native table shapes; native TS/TE interval, ordered data/rule spans and cell source rows. |

Two vertical-span recovery sources retain their native lint diagnostics; a
separate correct vertical-span source supplies clean acceptance. Seven sources
(three no-fill Nm/Ft-to-tbl and four active man links crossing structures) crash
the pristine HTML renderer while ASCII, UTF-8, tree and lint succeed. Their
failed HTML profiles are recorded explicitly, not
silently promoted to Pass. Consumer verdicts come from test execution; the
manifest does not claim an unexecuted UI or Markdown axis passed.

Native profile receipt status is independent from product pass/failure. Existing
lint-warning recovery inputs stay present. `PendingAssertions` is a recording
label; actual test execution, not a JSON flag, establishes product acceptance.
The matrix is not a claim of arbitrary-program completeness.

## Independent assertions

`execution_scopes.rs` loads through the public loader, validates the original
document and crosses the real JSON text protocol boundary. It then verifies:

- Actual surviving name-field prose words and their exact hard-row/word-gap
  projection, including bare zero advance and a genuinely finite `.ll`.
- One table per original TS/TE interval, all ordered data/rule spans, declared
  column capacity, exact cell text and native source rows. A semantic mdoc
  column-list wrapper is not confused with a source tbl owner.
- Actual sentinel glyph columns after the known common five-column native
  page origin is removed. Marker indentation does not stand in for BODY
  glyph position; signed local origins are not globally trimmed.

The two styled-table witnesses retain the positional code plus font/flag
suffix emitted by `tree.c::print_tbl`: for example `0Lb[A] 1Li[B]` still
describes two real cells. This prevents a native evidence decoder omission
from being mistaken for a product topology change.

The pinned source rules are `man_term.c::pre_SY/post_SY`, both dialects'
`print_*_node` table dispatch, `tbl_term.c::term_tbl`, and
`mdoc_term.c::termp_it_pre/post` plus display pre/post. Scope return restores
geometry after native post; it does not restore old word/device flags or
execute another output drain as a formatter line.

The complete manuals in `tests/fixtures/roff/real/field-boundaries` provide
unchanged source provenance controls. Existing scoped layout, name BODY,
recovered table, column, font, temporary-indent and Markdown matrices remain
separate permanent protections. Wider UI, portable Markdown, query and cost
axes are reported separately; native receipts are never promoted to consumer
Pass solely because reference processes exited zero.

```sh
cargo test --locked -p mant-engine --test roff_lowering execution_scopes
python3 -m unittest scripts.roff.tests.test_execution_scope_fixture
python3 -m unittest scripts.roff.tests.test_field_boundary_sources
```

The two DELIMO marker controls permit only moving the semantic list marker
before the authored opening parenthesis. They independently assert that
`(BEFORE` remains in one original item/paragraph owner, DISPLAY is +6 from
AFTER, AFTER/TAIL retain native origins, and two actual Markdown readers
preserve authored words, order and ordered/bullet identity. They do not claim
pristine marker-position equivalence.

## Consumer registrations and limits

The 609-source native/IR/JSON assertions are distinct from these finite
consumer subsets. Test execution receipts establish pass/failure; registration
here does not upgrade every source to every consumer:

| Entry | Registered exact source domain |
| --- | --- |
| CLI pipe plain/ANSI text | All 96 M1 core +120 M2 +20 M3, 472 child processes; no terminal viewport is claimed. |
| Actual 40/78-column Buffer | All M1 core and M3; 48 M2 root/tag/column/literal controls. |
| M2 public text 40/78 and two Markdown readers | All 120 source tbl cases; 12 nested column cases use the existing portable nested-table spelling. |
| Additional two Markdown readers | Eight M1 SY, twelve M3 display controls, two DELIMO controls and the separate styled name witness. |
| Actual 12-column App | Original tag/enum D1 source; backward search reveal, visual copy and same-App resize. |

Extended native-only sources do not inherit the core consumer verdict. Whole-
page device geometry/fonts, every owner/click range and a CLI PTY at both widths
remain outside this finite source matrix. Separate F4/F5 code-row and reference
matrices exercise their accepted/refused links, queries, artifact byte/scalar
ranges and painted 40/78-column copies. The complete real scmdctl source also
has an independent actual 40/78-column continuous-frame check.
